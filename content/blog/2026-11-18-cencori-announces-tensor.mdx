Today Cencori is announcing **[Tensor](https://www.tensorade.app)**, an agentic development environment. You describe what you want built, and AI agents plan, write, run and ship the code with you.

Tensor is open to everyone from today. It runs on Mac, Windows and the web, you can start on a free trial, and plans start at $2 (₦2,000) a month.

## What an agentic development environment is

An AI code editor suggests the next line and keeps you in the loop for every change. An agentic development environment hands an agent a whole task. The agent reads the codebase, makes a plan, edits files, runs commands and reports back. You direct the work, approve what needs approving and review the result.

The code is still yours to read and change. What changes is the unit of work: a task, not a keystroke.

Tensor is for anyone building software. Engineers can hand off whole tasks and review what comes back. People with an idea and no codebase can have an agent build it with them.

## What Tensor does

- **Runs every task until it's done.** The agent plans the work, writes the code, runs it and fixes what breaks before it reports back.
- **Works with the models you already use.** Tensor supports models from OpenAI, Anthropic, Google, DeepSeek, xAI, Meta, Mistral, Qwen, Kimi and Zhipu. Tensor can choose the model for each task, you can pick one yourself, or you can connect your own provider with your own API key.
- **Brings your setup with you.** Tensor imports an existing Claude Code or Codex setup and can keep the imported configuration in sync.
- **Extends with your tools.** Add plugins, skills, servers and hooks to connect the tools and services your work depends on.
- **Publishes what you build.** Every paid plan puts sites on the web at an address of their own, as many as you like. An app with a backend runs on a machine of its own, keeps its data and sleeps when nobody is visiting.

## Pricing

Every plan includes usage that refills each week. Usage is measured by what the models cost to run, so smaller models stretch it further.

| Plan | Per month | Model | Usage |
| --- | --- | --- | --- |
| Starter | $2 (₦2,000) | Tensor picks | Refills every week |
| Builder | $5 (₦5,000) | Tensor picks | 2.5x Starter |
| Pro | $15 (₦15,000) | Tensor picks | 7.5x Starter |
| Max | $20 (₦30,000) | You pick, frontier models included | Refills every week |
| Ultra | $100 (₦150,000) | You pick, frontier models included | 5x Max, two tasks at once |

On Starter, Builder and Pro, you describe the work and Tensor chooses the model that runs it. That is how a plan can cost $2. On Max and Ultra you choose any model yourself.

You can pay in naira or in dollars. Full details, including what each plan allows for published sites and apps, are on the [pricing page](https://www.tensorade.app/pricing).

## Why Cencori built it

Cencori's mission is to build and run AI infrastructure that is accessible to everyone, everywhere. Tensor runs on that infrastructure, and it puts the same mission in front of the people who build software.

Most agentic coding tools are priced for engineers at well-funded companies. A plan that starts at $2 and can be paid for in naira means a student in Lagos, a freelancer in Nairobi and an engineer in San Francisco can all work with an agent on the same terms.
