## Cloud Intelligence Provider (CIP)

Cencori is not just an "AI Proxy." We are a **Cloud Intelligence Provider (CIP)**.

- **AI Proxy**: A simple pass-through layer that forwards requests (e.g., Cloudflare AI Gateway).
- **CIP**: A fully managed infrastructure layer that provides unified request routing (AI Gateway) and end-user billing (Revenue).

## What happens to a request

1.  **Your app** calls Cencori with the SDK or the HTTP API.
2.  **Your key is checked**, along with the project's limits, budget and network rules.
3.  **PII protection (opt-in, off by default)**: if turned on in the project's **Settings → General**, the input is checked for personal data and blocked with `403` if any is found.
4.  **Routing**: Cencori sends the request to the right provider for the model, following your project's defaults and fallback rules.
5.  **The provider answers**, and the response streams back to your app.
6.  **Logging and billing**: the request is logged with its tokens, cost and latency, and billed to your credits (or to your provider account with BYOK).

## Your data

- **Logs** keep requests and responses so you can debug and audit them, for as long as your plan's log retention.
- **PII checks** run on the request and aren't stored.
- For data residency requirements, [contact us](mailto:support@cencori.com).

## Platform Limits

To ensure fair usage and stability, the following limits apply:

| Limit | Free | Pro | Team | Enterprise |
|-------|------|-----|------|------------|
| **Projects** | 1 | Unlimited | Unlimited | Unlimited |
| **Log retention** | 7 days | 30 days | 90 days | Unlimited |
| **Memory store** (per project) | 1,000 | 50,000 | 100,000 | Unlimited |
| **Memory ops** (search/write, per month) | 2k / 1k | 50k / 5k | 200k / 10k | Unlimited |
| **SSO/SAML, SLA, SIEM streaming** | — | — | — | ✓ |

Requests are not capped by plan — AI usage is metered and billed in prepaid credits, while BYOK calls bill the provider directly. Spend caps and rate limits are configured per project key.

## Keys & Authentication

- **Project Keys (`csk_...`)**: Scoped to a specific project. Used by your application SDKs. If compromised, only that single project is affected.
- **Organization Keys** (Coming Soon): Admin-level keys for programmatic management of multiple projects.

## Glossary

- **Gateway**: The unified entry point for all AI requests.
- **Billing**: The economic engine. Meter, limit, and charge users for AI usage.
- **PII Protection**: The opt-in check that blocks requests containing personal data, turned on in the project's Settings → General.
