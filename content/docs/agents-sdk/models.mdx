An agent takes any model in the [Cencori catalog](/docs/ai/models). Switching provider is changing one string.

```ts
new Agent({ name: 'Fast', model: 'gpt-oss-120b' });
new Agent({ name: 'Careful', model: 'claude-sonnet-4-5' });
new Agent({ name: 'Cheap', model: 'gemini-2.5-flash' });
```

## The default

Without `model`, agents use `gpt-oss-120b` on Cerebras (`DEFAULT_MODEL`): thousands of tokens a second and reliable tool calling, so agents with several tool rounds stay quick.

## Model settings

```ts
new Agent({
    name: 'Analyst',
    model: 'gpt-oss-120b',
    modelSettings: {
        temperature: 0.2,
        maxTokens: 2000,
        reasoningEffort: 'low', // 'none' | 'low' | 'medium' | 'high'
    },
});
```

| Setting | Effect |
| --- | --- |
| `temperature` | Lower is steadier, higher more varied |
| `maxTokens` | Cap on each reply |
| `reasoningEffort` | How long a reasoning model thinks first. Lower is faster. `'none'` turns thinking off; a model that cannot turn it off gets its lowest setting |

## Tools need a model that calls tools

Agents with tools, handoffs or widgets need a model that supports tool calling. Check `capabilities.tools` in `GET /v1/models`.

## Auto

`model: 'auto'` routes each call to a model on your own provider keys, by task. Your provider bills the model the call went to, at that model's price, and Cencori adds no charge, so `auto` has no price of its own in `GET /v1/models`. `result.steps` says which model answered each call.

## Models that are going away

`GET /v1/models` gives each model a `retires_at`: the day its vendor has said it will stop serving it (`YYYY-MM-DD`), or `null` when none is announced. `replaced_by` is what the vendor says to use instead.

```ts
const { data } = await cencori.models.list();
const soon = data.filter((m) => m.retires_at && Date.parse(m.retires_at) < Date.now() + 60 * 86_400_000);
```

## Your own keys

Bring your own provider keys (BYOK) in project settings and agents use them automatically: same code, your account's rates and limits.
