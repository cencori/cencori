Copilot is the assistant in the console. Tell it what your business does and what you want the agent to handle, and it builds the agent for you: instructions, knowledge, tools, products and alerts.

> "I run a lounge in Lekki. I want guests on WhatsApp to ask about the menu, book tables and pay a ₦20,000 deposit for VIP."

## What Copilot can do

- Create an agent and write its instructions.
- Update the instructions of an agent you already have.
- Add knowledge, like a menu, price list, FAQ or policies, from text you type or attach.
- Switch system tools on or off: payments, selling products, callbacks, hand-off and ending conversations.
- Add products to your catalog.
- Set up owner alerts.
- Publish the agent.
- Take you to the right page for what it can't do itself, like connecting WhatsApp or signing in to an app.

Ask "what's left to set up?" and it checks the agent and tells you.

## Confirmations

Copilot asks before it changes anything. Each change shows above the composer with what it will do; confirm it, or tell Copilot what to do differently.
